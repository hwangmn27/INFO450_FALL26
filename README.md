# INFO 450 – Programming for Business Analytics

Coursework and projects from **INFO 450: Programming for Business Analytics**, taken at **Virginia Commonwealth University (VCU)**.

## Course Overview

| | |
|---|---|
| **Course** | INFO 450 – Programming for Business Analytics |
| **Institution** | Virginia Commonwealth University |
| **Credit Hours** | 3 |
| **Prerequisites** | BUSN 212 or MATH 200 (min. grade C); junior standing (54+ credit hours) |

INFO 450 teaches how to apply Python to business analytics and data science problems. The course covers manipulating, cleaning, and analyzing large datasets, building data visualizations, and developing statistical models. By the end of the course, students are able to use Python to generate data-driven insights and build predictive models.

## What's in This Repo

This repository holds the assignments, labs, and projects completed for the course, organized as the semester progresses.

## Topics Covered

- Data cleaning and manipulation with Python
- Working with large datasets
- Data visualization
- Statistical modeling
- Data-driven insights and predictive modeling
